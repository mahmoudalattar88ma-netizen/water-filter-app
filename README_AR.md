# متابع فلتر المياه — مشروع APK

المشروع يحافظ على واجهة HTML الحالية ويضيف إشعارات أندرويد محلية: قبل الموعد بيومين وفي يوم التغيير، مع إعادة جدولة المواعيد بعد إعادة تشغيل الجهاز.

## بناء APK من الموبايل عبر GitHub
1. فك ضغط الملف وارفع محتوياته إلى مستودع GitHub جديد، مع رفع المجلدات والملفات الداخلية وليس ملف ZIP نفسه.
2. افتح تبويب Actions في المستودع وفعّل Actions إذا طلب ذلك.
3. شغّل `Build Water Filter APK` أو اعمل Commit على فرع `main`.
4. افتح آخر تشغيل ناجح، ومن Artifacts نزّل `Water-Filter-APK` وفك ضغطه لتحصل على `app-debug.apk`.
5. ثبّت APK واسمح بالإشعارات. على بعض أجهزة أندرويد، استثنِ التطبيق من توفير البطارية لتحسين موثوقية التنبيه.

ملاحظة: تنبيهات أندرويد مجدولة محليًا؛ التوقيت قد يتأثر بقيود توفير الطاقة الخاصة بالشركة المصنعة. التطبيق يحتاج أن يظل مثبتًا، ولا تستخدم إيقاف إجباري له.
